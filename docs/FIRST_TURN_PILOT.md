# v6 定向自主展开与灰后恢复

这是内部局部集成入口，不是正式全构筑 v6。冻结原赛事主41／额外15、资产、core、OCG/MR5、seed1和Rusty＋盖放Fog目标均未改变。

起手为 Decayed Cloak、Tsuchinoko、Soleret、Torn Scales、Doll Hammer。搜索先冻结最多8个自主方案，再选择首个以Scythe为首敏感效果的候选。该选择属于定向集成实验，不是无干扰最高排名推荐。人工对照配方仅在独立测试中使用，搜索实现不读取配方。

本机两次三组实验均通过：

| 组别 | 实际结果 | 调用（含查询见证及首次独立重放） |
|---|---|---:|
| 无干扰 | 自主9步达成Rusty＋Fog，并完成结束阶段 | 72 |
| 原方案受阻 | Scythe第5步收益被无效；继续原动作，到第8步缺少Greaves连接素材 | 43 |
| 自主恢复 | 从第5步后的实际闭链窗口搜索，改为检索并特召Boots，达成同一目标 | 55 |

每组上限512，总计170／1536。恢复独立重跑中断前缀，费用如实计入；没有从后续继续执行、消耗资源的受阻终点恢复。两次冻结候选和恢复方案ID、分组账本一致。这里未开展48手正式评估。

运行原生集成测试：

```text
cargo test --offline -p ygo-planner --test first_turn_autonomous autonomous_generated -- --ignored --nocapture
```

需已准备冻结资产、本机开发worker配置和快照。报告及持久账本保存在本地 `data/runtime/tournament-2026/pilot-autonomous/<run>/`，不提交卡库、引擎产物或运行报告。重复实验另外收费。

局部报告v1记录实际起点、冻结方案、每个显式选择之前的检查点、结构化候选比较、费用及预计资源变化、后续用途、实际差异、灰后锚点和独立查询／整条线路重放引用。方案重新计算知识、目标、限制、起点及完整语义步骤身份；执行合同逐项核对持久调用结果、原始前缀、实际查询和目标。导入报告还须通过 `replay_partial_execution` 重新取得原生查询，不由JSON授予资格。
