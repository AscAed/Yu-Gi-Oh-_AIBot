# 实施取舍与交付边界

历史决策记录：这些取舍形成于 M0–M4 阶段，不是当前完整实现范围或现行待办。当前架构与状态见 docs/INDEX.md 和 TASKS.md。

2026-10-19产品目标确认后，早期“HTTP最后做”不再是全局依赖；见[路线图](ROADMAP.md)。下列历史条目仍保留当时事实，不据此阻塞产品基础或扩大现有能力。

1. 沿用指定工作目录、建立codex/combo-mvp分支：多数现场脚手架未跟踪且不在HEAD，新worktree会遗漏。代价是以后另开并行工作需主动隔离。
2. Windows Lua Meson拼接改为Python：上游cmd/type对本机路径失败，核心/Lua源文件不变且只允许精确适配。代价是构建适配需维护；已记录哈希和源码树。
3. 复制proc_unofficial.lua公共辅助库到脚本根：官方utility无条件加载它，不导入unofficial卡片或数据库。代价是上游公共库改变时需重新核对依赖。
4. beam在召唤/发动历史间分配名额：保留支付费用中的展开，不合并完整隐藏状态。代价是仍可能裁掉更优线路。
5. worker连续执行单合法选项：仍由core逐步结算，全部写入resolved_decisions。代价是节点表示前缀执行次数，决策深度另计。
6. 保留未跟踪脚手架，不自动提交整个仓库：避免把原有工作混入提交。代价是后续需挑选本次交付文件再提交；未推送或合并。
7. 每层轮换预选响应：降低区域变体进程调用成本，未执行选择记入pruned。代价是可能遗漏更强出口，只报告当前预算内排名。
8. 首版评分限定rabbit-v1：其它效果强度计零且明确缺口，代价是正式卡组尚需扩充评估规则。
9. 墙钟截止允许线路集合变化：固定节点预算回归保持确定性，代价是跨机器时间预算结果不能保证相同。
10. 对手策略、手坑、后攻和HTTP按批准路线延期：当前版本只提供本机先攻无干扰推演。

独立评审的Minor延期：加强报告JSON Schema嵌套负例；当前Rust合同和引擎重放严格校验实际报告。
