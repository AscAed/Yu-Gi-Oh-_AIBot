# 本机部署包文档入口

此文件是 `dist/ygo-local/README.md` 的源模板；部署脚本按包目录位置改写下列相对链接。

- [当前文档入口](INDEX.md)
- [当前任务与状态](../TASKS.md)
- [当前部署说明](DEPLOYMENT.md)
- [当前验证记录](TESTING.md)

这些链接指向当前仓库工作区，内容可能在部署后改变，不能证明与本包构建时的源码或验证结果一致。核对本包的 CLI 和 worker 身份时使用包内 `build-hashes.json` 及相应构建记录。

包根目录中的其他 Markdown 文件是部署时复制的文档快照。原文链接按仓库的 `docs/` 目录布局编写；扁平复制后，部分相对链接和本机证据路径在包内不可用。`TESTING.md` 到同目录 `TESTING_HISTORY.md` 的历史记录跳转随部署脚本一同复制。历史证据仍可能依赖仓库中被忽略的 `target/` 或 `data/runtime/` 文件。

此包的配置绑定本机绝对资产路径，上述链接也依赖 `dist/ygo-local` 与仓库的原有位置。移动包、删除仓库或资产后，这些路径可能失效；本包不是独立可移植的文档或运行环境。
