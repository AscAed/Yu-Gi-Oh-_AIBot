## 系统边界

- ocgcore 是效果结算权威；人工知识负责生成有限预测/候选，不能覆盖或伪造引擎事实。
- 搜索和评分是不同维度。评分是 profile 定义的启发式，不能称胜率或实战强度。
- engine verified 仅适用于所需输入、提示、状态、结算与独立重放均完整的报告。未知关键消息、未知规则、报告不一致、故障和预算不足必须降级或拒绝。
- 线路可执行、知识可信度、搜索完整性及全局最优是四个维度；独立重放不能证明不存在更优分支。概率/循环与证明范围见[研究定义](OPTIMALITY_RESEARCH.md)。
- 数据、引擎、规则表、知识包、Schema、profile、预算和报告都应可追溯到版本/哈希。
