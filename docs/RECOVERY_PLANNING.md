# 指定灰流丽与恢复规划

实施基线：17f0e68。已批准范围：灰流丽响应 Torn Scales 首次送墓；无干扰、原计划受阻和实际状态恢复三组；每组执行和重放共享512次预算，合计最多1536次。

## 使用

部署后使用同一套冻结资产：

```powershell
dist/ygo-local/ygo.cmd combo plan --input tests/fixtures/ash-recovery.request.json --output data/runtime/ash-recovery-report.json
dist/ygo-local/ygo.cmd combo plan-replay --input data/runtime/ash-recovery-report.json
```

请求保存完整己方牌组、五张起手、seed=1、目标和固定对方资源。对方40张牌组由己方主牌组替换一张Ryu-Ran为灰流丽组成；移入手牌后剩39张牌库。三组使用同样的资源，无干扰组只是放弃响应。它是合成局面，不代表完整后攻对局。

规划请求/报告、分析与运行协议均为v4；profile为`phantom-recovery-v1`，初始化为`fixed-interruption-v1`。内部组报告复用v3目标请求结构，执行协议和证据合同使用v4。旧v1/v2/v3入口、profile、事件和身份路径保持独立。原十二卡知识包不改写；灰流丽条目以冻结正文和脚本哈希与原包组成独立知识身份。

## 三组与预算

- `baseline`：先生成至多8个候选，选取排名最高且经过重放验证的线路。不事先规避灰流丽。
- `interrupted`：在第一只Torn Scales第一次送墓的实际连锁窗口，绑定对方手牌灰流丽的真实选项。保存原方案首次无法继续的合法前缀，它不是终场。
- `recovery`：重跑同一决策前缀，在连锁结束后的己方主阶段操作窗口重新规划；目标不变。

每组最多512次调用，执行、实际探测、内部见证验证和外部重放共用账本。`total_calls`包括为外部重放保留的调用，合计上限1536。跨组重跑前缀按实际调用计数。每组最多5000次符号展开、frontier 32、8个主候选和8个辅助候选；完整线路最多32个语义步骤。恢复余量按实际被中断步骤的位置扣除，包括此前Boots特召和对方灰流丽发动。

排序沿用目标满足、已验证收益向量、己方手牌及场上资源、决策成本、稳定推荐ID。`--scoring`、`YGO_SCORING_CONFIG`、默认值的优先级不变；诊断分数仍为启发式。

## 证据与安全降级

灰流丽无效效果，不无效发动。费用和Torn Scales已用次数保留；原送墓未发生，不加入预测收益或成功结算历史。正常召唤机会和此前Boots自行特召次数由实际历史恢复。费用前后的发动源身份、CHAINED费用后快照、实际无效和结算分别记录；CHAINING后才发生的手牌费用MOVE也必须绑定同一实例。

恢复状态来自实际检查点和事件；实际前缀历史同时进入目标预测、辅助探索及解释，不把已经发生的召唤误认为尚未完成。所有选择理由保存于引擎执行之前，成功线路及其逐次选择前的见证分别独立重放。前缀必须与无干扰组的实际选择一致；场景、策略、知识身份、锚点和规划版本进入相应身份。

当前恢复锚点限定为早期首个Scales送墓与灰流丽连锁。此前已有其他效果连锁、未决触发、素材状态、缺失身份或历史时返回`recovery_coverage_gap`，不猜测隐藏限制。锚点之后仍复用既有效果、素材及历史规划能力。通用目标表达式不代表任意手坑、任意中断点或任意卡效均可恢复。

失败使用`category`和原始`detail`区分响应点未到达、响应不合法、原计划受阻、恢复覆盖不足、提示绑定失败、预算耗尽、引擎失败和未找到恢复方案。未找到方案不是全局无解；已经完成的验证结果保留。合同重新计算失败分类，拒绝伪造成功标志、预算、恢复状态、历史、预测和引用。
