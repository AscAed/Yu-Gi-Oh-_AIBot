# Windows Combo MVP implementation plan

Goal: fixed five-card hand, OCG/MR5 first-turn search using pinned x64 ocgcore,
heuristic end-board scoring, and independently replayed CLI reports.

The user-approved plan in the implementation chat is authoritative.

- M0: pin core 38d04c9feb1a26617407091380634c87262fe3f8 and Lua
  6e22fedb74cf0c9b6656e9fce8b7331db847c605; build x64 using Meson/Ninja;
  verify C/Rust ABI and API 11.0; implement protocol v2.
- M1: import official local CDB and pinned OCG LFList into immutable hashed
  JSON snapshots; validate aliases, zones and opening hand.
- M2: isolated worker with data/script callbacks, framed messages, typed
  prompt responses and state queries; settle End Phase before stopping.
- M3: deterministic bounded beam search by replaying full prefixes; separate
  engine verification and heuristic evaluation; replay returned lines.
- M4: catalog/banlist import/status, deck validate, engine doctor/smoke,
  combo analyze/replay; Windows deployment package and two-tier CI.

Defaults: top_k 5, 10,000 nodes, width 32, depth 64, 60s total, 30s worker.
Regression: Rescue Rabbit, normal monsters, Xyz/Link exits, end-phase cleanup;
malformed protocol, timeout/crash, missing script, alias/hand mismatch,
identical visible states with different histories, config-driven scoring.

Execution: superpowers:executing-plans; preserve existing untracked scaffold.
