## 双轨小步路线

| 顺序 | 任务 | 交付与退出条件 |
|---|---|---|
| D3 | 文档与证据收敛 | 16项愿景需求均可追踪到差距、阶段和验证入口；E1、W1及当前源码身份一致；历史计划保留其时点范围 |
| W1-A | 工作台安全与任务冻结 | 所有状态变更方法有同源Origin保护；合成适配器覆盖草稿revision、完整牌组校验、资产身份和预算冻结 |
| W1-B | 排队与结果边界 | 验证单运行加单排队、只取消排队任务、持久化顺序、重启未知状态、预算截断和报告展示；不伪造进度或自动重发 |
| W1-C | 本机分析验收 | 合成门禁通过后固定Rabbit输入、资产身份、调用与停止边界；本机真实分析另列执行验收，不由设计默认授权 |
| L1 | 中文数据复核 | 分批核验39卡名称、正文、别名、字段、语言类别和使用/再分发依据；证据不足保持未知 |
| R1b-3 | 真实恢复实验设计 | 定义固定场景、独立scope、预算、窗口、消费记录、暂停/重开和独立重放标准；执行另行授权 |
| W2 | 普通用户发布准备 | 干净环境检查启动、资源路径、草稿、导入导出和升级；分别记录源码、产物和资产身份 |
| P1 | 单一阻断研究 | 每批只选动作完整性、观察投影、条件概率、自然结束或循环之一，交付可复现实验结论；Ground Collapse仅为候选 |
| M1 | 阶段复盘 | 按实际人时、运行耗时、内存、调用和证据体积选择下一批；P4按R2→R3→R4→R5推进 |

W1与L1可独立推进。W1-A先于W1-B，W1-C须等待合成门禁；R1b-3的设计不能启动真实scope。工作台工程不等待P1全部准入或P4全部规则认证。Curry pin处置须先取得Curry自身归档、构建及请求/收据来源链；不能通过改pin消除历史失败。

## 方案与研究约束

逐卡人工模型适合P4和定向规则认证，但全卡维护与组合成本未知。完整引擎搜索保留执行权威，尚未解决全动作、随机性、隐藏信息、循环和证明规模。推荐研究“语义辅助排序、引擎执行、独立证明”：先用语义改善搜索顺序，仅允许有独立可核查安全依据的规则用于证明性剪枝。模型可以提出候选，不认证卡效、互动或剪枝。

维持愿景中的全正式OCG、隐藏信息和全局最优门槛。局部案例、固定预算成功线路、逐线路重放和测试通过数均不能替代全局搜索完整性及独立值界。未知、预算截断、循环和无有限最优值须分别披露。
