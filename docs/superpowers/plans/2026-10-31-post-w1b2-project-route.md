# W1-B2后的项目定位与双轨路线

本轮文档基线为2026-10-31本地`main / 6191011`，起始工作区干净。目标唯一事实源为[产品愿景](../../PRODUCT_VISION.md)，当前状态由[任务表](../../../TASKS.md)维护。

## 项目位置与差距

项目是具备牌组草稿工作台的有限场景研究原型。P0正式OCG发行分母未闭合；P1完整动作、信息策略、条件概率、循环和独立值界仍阻止完整小问题准入。P2/P3已有39卡字段盘点和草稿工作台，正式中文数据、分析流程及普通发布包仍缺。P4真实恢复和独立重放未认证，R2规则认证、R3正式v6、R4评估及R5双资产部署开放。P5–P8通用知识、构筑反馈、全卡覆盖及可核查最优性证明未完成。16项需求的差距和阶段入口见[项目评估](../../PROJECT_ASSESSMENT.md)。全卡和最优性仍有未证明可行的研究关口，不能据测试数估算总完成百分比或承诺工期。

W1-B2提供进程内单运行、单排队、取消和票据结算；W1-B3提供任务revision/报告存储及持久先行协调器。W1-B3.3内部合成故障矩阵覆盖提交前失败、提交后不确定、重开分类、报告孤立、重复终态、冻结资产漂移及已提交revision后的操作系统子进程强杀。矩阵不验证逐syscall强杀、断电/介质故障、HTTP或真实执行；提交后锁内内存应用没有可返回错误分支。B2容量/领取/取消/结算在线程锁内线性化，执行票据在锁外使用；运行中不可取消，终态不重复结算，unknown不自动重发。报告校验绑定冻结请求并认证文件字节完整性，不认证报告来源或真实执行。B3验证见[持久化记录](../../WORKBENCH_ANALYSIS_PERSISTENCE.md)及[TESTING](../../TESTING.md)顶部。HTTP创建幂等、随机源故障和锁中毒注入仍待对应批次定义/验证。详见[W1-B2交接](2026-10-31-w1b2-analysis-queue-handoff.md)。

规划阶段静态核对旧普通包CLI/worker哈希与清单一致、六个主要配置路径存在；旧包是2026-10-19构建，不能证明当前源码部署。普通包与赛事配置历史doctor、历史smoke/replay及CI各自按日期和身份读取[TESTING](../../TESTING.md)。W1-B2本机Rust 377 passed/36 ignored、相关Python 30 passed/2 skipped属于历史合成验证；引用对话记录PR #16 CI通过，本轮未重跑。历史证据的SHA-256清单不是备份；符号链接策略限制和P4-R5仍开放。Tenki历史pin和失败保留，Curry来源链未知。

## 小步路线

| 任务 | 依赖与退出条件 |
|---|---|
| D6 文档收敛 | W1-B2、源码身份、部署及16项需求可追踪；旧计划标明历史时点 |
| W1-B3.1 任务记录持久化 | 已交付独立revision存储；严格链校验、排他锁、重启分类通过定向测试 |
| W1-B3.2 报告文件存储 | 已交付严格合同/冻结输入绑定、原始字节SHA-256、私有落盘和重读校验的合成验证；来源和真实执行仍未认证 |
| W1-B3.3 终态与持久协调 | 内部合成提交点故障、停派发、重开分类、重复终态、资产漂移及进程强杀矩阵已交付；HTTP创建幂等和底层介质故障不在本批范围 |
| W1-C 本机分析验收设计 | 合成门禁通过后固定Rabbit输入、资产身份、调用及停止条件；真实执行另行安排 |
| L1 中文数据 | 分批核验39卡名称、正文、别名、字段、语言类别和使用/再分发依据；缺证项保持未知 |
| R1b-3 恢复实验设计 | 固定场景、独立scope、预算、窗口、消费、暂停/重开和独立重放；真实执行另行授权 |
| W2 发布准备 | 干净环境核验启动、路径、草稿、导入导出和升级；分别绑定源码、产物和资产身份 |
| P1 单一阻断研究 | 每批选择动作完整性、观察投影、条件概率、自然结束或循环之一，交付可复现结论 |
| M1 复盘 | 按人时、耗时、内存、调用和证据体积选择下一批；P4按R2→R3→R4→R5推进 |

W1-B3各小批依次推进，L1可独立推进。Ground Collapse仅为P1候选，旧准备材料不自动授权执行；Curry pin处置依赖其自身归档、构建及请求/收据来源链。未知消费或身份不一致时停止并保留证据。

逐卡人工模型适合定向认证但全卡成本未知；完整引擎搜索保留执行权威但动作、信息、概率、循环及证明规模未解决。推荐研究语义辅助排序、引擎执行、独立证明；证明性剪枝必须有独立可核查安全依据。执行重放、搜索完整性与最优性分别证明。
