# W1-B2 内部合成队列交接

实施基线：codex/tournament-deployment-audit-20261031 / b999a1e。保留原有未提交文档修改。

新增进程内 AnalysisJobQueue：enqueue/snapshot/claim_next/cancel/settle。一个运行槽及一个排队槽；首任务未领取时已占唯一排队槽。容量、领取、取消和结算在同一 Mutex 内线性化；执行者仅在锁外使用自有 DispatchTicket。ID为系统随机生成，生命周期内不复用；终态返回调用方并从活动队列移除。票据不可序列化，记录绑定ID/revision/输入摘要，结算重核runtime白名单。

失败不修改活动状态；取消成功永不派发；运行任务不可取消；终态回调不重复结算、不自动领取下一任务。unknown不自动重发。报告引用仅作结构校验，完成与截断来自合成测试，不认证报告文件或执行资格。

测试日志、红测与独立只读审阅位于 ../../../target/w1b2-analysis-queue-tests/。实际汇总见 TESTING。红测为缺少queue模块的E0432；最终覆盖并发入队、领取/取消及重复结算屏障、时间/revision/绑定/报告错误、准确终态及失败快照不变。

不增加HTTP、界面、CLI参数、schema、文件存储或正式执行器。本批原生研究、真实runner、worker及引擎FFI为0；随机ID使用操作系统随机接口。未运行doctor、真实资产opt-in、48手评估；未部署、提交或推送。

## 失败矩阵

| 边界 | 结果 |
|---|---|
| 排队槽占用 | analysis_queue_full，活动记录不变 |
| 取消已运行任务 | cannot_cancel_running，不干预执行 |
| 旧revision/时间倒退 | 复用B1稳定错误，状态不变 |
| 陈旧、重复或跨任务票据 | analysis_ticket_mismatch，不结算其他任务 |
| 输入绑定/报告结构错误 | 拒绝，保留运行任务供调用方处理 |
| 无法认证完成 | 显式分类unknown，不自动重发 |
| 互斥锁中毒/随机ID失败 | 稳定错误，停止操作 |

未覆盖操作系统随机故障注入和锁中毒注入；实现有拒绝分支，但不将其记为已实测。未实施进程生命周期、任务重启恢复或实际报告验证。
